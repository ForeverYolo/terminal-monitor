📖 使用指南

欢迎使用 Screen Web Terminal

这份指南会从零开始，一步步教你怎么用浏览器打开、查看、操作远程电脑上的命令行窗口——不需要装任何软件，手机和电脑都能用。

🚀 3 步开始使用

如果你已经拿到了网址和密码，看这里就够了
1

打开网址

在浏览器（手机或电脑都行）里打开管理员给你的地址，会看到一个登录框。

2

输入密码登录

用户名随便填什么都可以，密码要填对。登录后浏览器会记住密码，下次自动进入。

3

点击一张卡片

登录后会看到若干张卡片，每张代表一台正在被监控的电脑。点一下就能进入它的命令行窗口，直接开始操作。

这是什么

用一句话说清楚它是干什么的

简单说：你的某台电脑上正在运行一个"Screen 会话"（可以理解成一个不会因为断线而消失的命令行窗口），这个工具能让你透过浏览器，从任何地方看到这个窗口里的内容，还能像本人坐在那台电脑前一样打字操作它。

它是怎么做到的：那台电脑上装了一个很小的"代理程序"，主动连接到一台中转服务器；你打开网页登录的，也是连到这台中转服务器。服务器负责把两边的画面和键盘输入互相转发。

好处是：那台远程电脑不需要公网 IP，不需要装 VPN，你也不需要装任何客户端软件——一个浏览器就够了。就算你把网页关掉、手机锁屏，远程那边的程序也会继续运行，不会因为你断开连接就被打断。

登录

第一次打开网站时会看到的画面

  • 用户名：随便填一个方便自己识别的名字就行，不影响能不能登录成功。
  • 密码：管理员分配的登录密码，必须填对。

登录成功后，密码会被安全地记在你这台设备的浏览器里，下次打开网页会自动帮你登录，不用每次都重新输入。如果长时间没有操作导致连接断开，页面会自动尝试重新连上，不需要手动刷新。

💡
如果一直显示"Connection lost"或者提示密码错误，先确认密码有没有输对；如果确定密码没问题，可能是服务器暂时不在线，联系管理员确认一下。

仪表盘

登录后看到的主页面，每张卡片代表一台被监控的电脑

⭐ my-server screen: main
ubuntu-box · alice@192.168.1.10
正在跑着的最后几行输出…
claude: working

卡片上的信息代表什么

元素含义
⭐ 星标点一下可以把常用的机器置顶，方便下次快速找到
绿色圆点这台机器正在运行，没有在等你输入
红色圆点命令行停在一个"提示符"上，可能在等你操作
彩色小胶囊（claude: xxx）如果这台机器在跑 Claude Code，这里会显示它当前的状态，比如正在思考、在等你确认、需要你选一个选项
右上角的标签管理员给这台机器打的备注标签，比如 gpu / dev

三种查看模式

🗂️

卡片

默认模式，逐个查看每台机器，点哪张卡片就进入哪台的终端。

🖥️

多屏

电脑端专属，可以同时勾选多台机器，在同一个画面里并排查看（手机屏幕太小，已经隐藏这个功能）。

⚙️

管理

面向管理员的高级功能，可以新增/关闭节点、调整自动巡检设置，详见下方"管理面板"一节。

右上角还可以按 名字 / 编号 / 最近使用 排序，排序不会因为机器上下线而跳动。

终端界面

点进一张卡片之后看到的画面——一个和远程电脑一模一样的命令行窗口

电脑端可以直接用键盘打字，就跟本地开了一个终端一样，光标在哪、你打字就输入到哪。窗口大小也会自动适配你调整浏览器窗口的大小。

右上角有几个悬浮按钮：

  • ← Back：返回仪表盘（不会中断远程正在运行的任务）
  • 📤 / 📥：上传文件到远程电脑 / 从远程电脑下载文件，见下面"文件传输"一节
💡
关掉网页、手机锁屏，或者退出应用，都不会影响远程电脑上正在跑的程序——那是完全独立运行的，你只是"暂时看不到"而已，重新打开网页再进去就能接着看。

手机端说明

手机屏幕小，操作方式和电脑不太一样，这里单独说明

底部工具栏

进入终端后，屏幕下方会出现一排按钮，方便没有实体键盘的时候操作：

按钮作用
↑ ↓ → ←方向键，等同于电脑键盘的方向键
Tab Esc补全 / 退出，跟电脑键盘一样
Ctrl + 字母先点一下 Ctrl 按钮（会高亮），再点字母按钮，等同于按住 Ctrl 再按那个字母（比如 Ctrl+C 中断程序）
Home End ⌫行首 / 行尾 / 删除一个字符
键盘唤出下方的文字输入框，适合打长文字（中文输入法也能用）
⇞ 上翻 / ⇟ 下翻向上/向下翻看历史内容——手机上用手指滑动有时候翻不动，用这两个按钮最可靠
⤓ 最新一键跳回最新的内容（翻历史翻晕了就点这个）

"原始 / 结构" 切换按钮

终端页面右上角有个圆形按钮，可以在两种显示方式之间切换：

🖥️

原始

还原真实的终端画面，默认使用这个——像 vim、htop 这类全屏程序，只有在这个模式下才能正常显示。

💬

结构

把内容整理成像聊天记录一样的可读文字，专门为 Claude Code 优化，需要"是/否"确认或选择选项时会在下方直接出现按钮，不用自己找位置点。

如果只是在用 Claude Code、不需要看全屏程序，"结构"模式在小屏幕上会读起来更舒服；其它情况建议留在"原始"模式。

文件传输

终端页面右上角的 📤 / 📥 按钮

  • 📤 上传：把你设备上的文件发送到远程电脑当前所在的目录下
  • 📥 下载：浏览远程电脑当前目录下的文件并下载到你的设备

"当前目录"指的是远程那边命令行此刻所在的文件夹（跟你在电脑上 cd 到哪个文件夹是一个概念）。单个文件最大支持 200MB，只能访问远程电脑该用户自己的主目录范围内的文件，出于安全考虑不能访问其它地方。

安装与部署

面向从零开始搭建这套系统的人——需要用到命令行，但每一步该敲什么字都会写清楚

🙋
如果你只是被别人邀请来用这个网站的，这一节可以跳过，不影响你正常使用前面几节介绍的功能。

需要准备什么

☁️

一台"服务器"

一台有公网 IP、24 小时开机的 Linux 主机（比如阿里云/腾讯云的云主机），所有人都通过它访问网页。

💻

若干台"被监控电脑"

你想远程查看的那些电脑，不需要公网 IP，甚至可以在内网/家里，只要能连上外网即可。

两边都需要装了 Linux 系统，并且你能用 SSH 登录进去敲命令（Windows 上可以用 PuTTY 或者 Windows Terminal，Mac / Linux 自带的"终端"App 就能直接用 ssh 用户名@服务器地址 连接）。如果这一步不知道怎么弄，找懂的朋友帮忙连上去就行，后面的操作都是照着敲命令，不需要额外的知识。

第一步：把代码放到机器上

服务器和每一台被监控的电脑，都需要把这个项目的代码复制过去（比如用 git clone，或者直接把文件夹传上去），放在哪个目录都可以，记住这个目录，后面的命令都要在这个目录里执行。

第二步：部署服务器（只需要做一次）

1

登录服务器，进入代码目录，执行：

bash install.sh server

2

依次回答几个问题

监听端口（不确定就直接回车用默认值）、网页登录密码（自己设一个，记住它）、公网 IP 或域名（一般会自动探测出来，直接回车确认即可）。如果之前部署过，脚本会先把上次的配置读出来给你看，直接回车就是"沿用上次的设置"。

3

脚本会自动搞定剩下的事

检查/安装 Node.js 和 screen、安装依赖、启动服务，并且会验证是不是真的启动成功了（不会出现"看起来装完了其实没跑起来"的情况）。

4

记下最后打印出来的几行信息

访问地址、登录密码、Client Token——尤其是 Token，下一步部署每台被监控电脑的时候都要用到这同一个 Token。

第三步：在每台要监控的电脑上部署客户端

1

先手动建一个 screen 会话，跑你真正要监控的东西

screen -S 随便起个名字，进去之后跑你的程序（或者先跑个 bash 占位也行），然后按 Ctrl+A 再按 D 退出（不是关闭，是"放到后台"）。这个"名字"接下来会用到。

2

在这台电脑上执行：

bash install.sh client 刚才那个名字

3

依次填入：

服务器地址（上一步记下来的访问地址）、Token（上一步记下来的那个）、给这台电脑起个显示名称（随便起，方便在网页上认出是哪台）、标签（可选，直接回车跳过也行）。

4

完成

刷新网页仪表盘，这台电脑就会出现在卡片列表里了。以后想再加新的被监控电脑，重复这一步就行，每台机器都需要单独部署一次。

💡
同一台电脑上想同时监控好几个 screen 会话，也是重复第三步，每次换一个不同的 screen 名字即可；或者部署完之后直接在网页"管理面板"里点"新增节点"，不用再登录到那台电脑上手动操作。

配置文件字段说明（进阶，一般不需要手动改）

上面两步跑完之后，脚本会自动生成配置文件，正常使用不需要手动编辑，了解一下大概长什么样就好：

文件作用
config.json（服务器上）网页登录密码、监听端口、允许连接的 Token 列表都在这里
config.client-会话名.json（每台被监控电脑上）要连接哪个服务器地址、用哪个 Token、显示名称、监控哪个 screen 会话

安装过程中可能遇到的问题

没有 sudo 权限，装不了 Node.js
脚本会自动提示一种不需要权限的安装方式（下载一份独立的 Node.js 放到项目目录里），照着提示的命令敲就行，装完之后重新跑一遍部署脚本会自动认出来。
安装依赖（npm install）失败，提示跟编译有关的错误
这台电脑上大概率缺少编译工具，装一下就好：apt-get install -y build-essential python3（需要 sudo/root），装完重新运行部署脚本即可。
提示"未找到名为 xxx 的本机 screen session"
说明忘了第三步的第 1 小步——先手动用 screen -S 名字 建好这个会话，再回来部署客户端。

管理面板（面向管理员）

这一节涉及新增/关闭节点等操作，普通用户一般用不到，谨慎操作

切到仪表盘右上角的"管理"模式，可以看到按所属机器分组的节点列表，每一行是一个正在被监控的节点。

新增节点

在某台机器的分组里填一个新的 screen 名字、选择要运行的程序（bash / claude / sh），点"新增节点"，会在那台机器上新建一个 screen 会话并自动开始监控，不需要登录到那台机器上手动操作。每台机器最多 20 个节点。

停止监控 / 终止节点 —— 这两个按钮务必分清楚

⚠️
"停止监控" 只是让这个节点不再出现在列表里，远程那边的任务本身完全不受影响，该干嘛还继续干嘛。"终止节点" 会把远程那个任务一并杀掉，无法撤销，点之前会有二次确认，请确认清楚再点。

督工设置（可选的自动巡检功能）

如果开启，系统会定期检查各节点状态，在长时间没有响应时提醒你；如果配置了一个"分析员"节点（一个专门运行 Claude Code 的机器），还能定期生成整个机群的文字摘要。这是可选的高级功能，不开启完全不影响正常使用。

常见问题

登录页面一直显示 "Connection lost"
先确认密码有没有输对，输错密码也会先短暂显示别的提示、再变成这句话（这是已知的显示顺序问题，不代表出了两个不同的故障）。密码确认没问题的话，可能是服务器暂时没启动，联系管理员确认。
仪表盘上看不到我的电脑
说明那台电脑上还没有装好对应的监控程序，这一步需要管理员操作，找管理员帮忙添加。
手机上手指往上划，看不到之前的内容
用底部工具栏的"⇞ 上翻" / "⇟ 下翻"按钮，比手势滑动更可靠，详见"手机端说明"一节。
不小心点了"终止节点"，任务没了怎么办
这个操作无法撤销，任务已经被关闭了。需要管理员在那台电脑上重新开一个同名（或新名字）的 screen 会话，再重新添加监控。
密码忘记了 / 想换个密码
登录密码由管理员统一设置，找管理员帮你确认或修改。
输入的字符会自动换行，看起来很奇怪
通常是窗口大小跟远程程序预期的不一致导致的，试试把浏览器窗口调整一下大小（或者手机转个方向再转回来），终端会自动重新适配；如果一直有问题，联系管理员看看是不是需要重新连接一下这个节点。
能不能在多台设备上同时登录同一个账号
可以，同一个密码可以在任意多台设备/浏览器上登录，互不影响，都能各自独立查看和操作。

名词解释

服务器负责转发画面和输入的中转站，你登录网页连接的就是它，需要一直保持在线。
客户端 / 节点装在被监控的那台电脑上的小程序，负责把命令行画面发给服务器。
Screen 会话一个不会因为断线而消失的命令行窗口，是实际运行你的程序/任务的地方。
Token客户端用来证明自己身份的一串密钥，普通用户不需要关心。
Claude CodeAnthropic 出品的命令行版 AI 编程助手，如果远程电脑上跑的是它，卡片上会显示彩色的状态胶囊。
有其它问题？联系你的管理员。
